Frequently asked

Good questions.
Straight answers.

Does Zenith really work without any internet connection?+

Yes – completely. All three AI models, the database and the web interface run on the device itself. Zenith never phones home: no telemetry, no license checks, no cloud fallback. You can operate it in a fully air-gapped network.

Which file formats does Zenith understand?+

PDFs, Word, Excel, PowerPoint, e-mails and images (JPEG, PNG, TIFF – including scans and photographed documents). The vision model reads documents like a human: tables, stamps and even handwriting are captured.

How many users can work with Zenith?+

As many as you like. Zenith runs as a web application in your local network – every device with a browser can access it. There are no per-user licences and no artificial limits.

What happens to my data if the hardware fails?+

Your original files always stay in your file system – Zenith works with copies and indexes. The Professional and Premium packages additionally include an external RAID system and automatic local backups for business-critical redundancy.

Do I need IT expertise to run Zenith?+

No. The device arrives pre-installed and configured – connect power and network, open the browser, done. Setup takes less than 30 minutes. The Premium package even includes remote setup by our experts.
